# Todo App (React + TypeScript + Vite)

## Описание проекта
Приложение для управления списком задач с возможностью фильтрации и сохранением состояния в `localStorage`.

### Функционал:
- Добавление задач (с валидацией пустых строк и пробелов).
- Переключение статуса выполнения.
- Удаление задач.
- Фильтрация (Все / Активные / Выполненные).
- Персистентность данных через `localStorage`.

## Технологический стек
- React 18
- TypeScript
- Vite

## Запуск проекта

1. Клонировать репозиторий:
```bash
git clone https://github.com/saydum/todo-app-react-ts
cd todo-app-react-ts
npm run dev
# Run server http://localhost:5175/
```
